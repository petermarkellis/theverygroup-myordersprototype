# My Orders Prototype

This repository contains a crude mock prototype for the design exercise of the My Orders page. The prototype allows users to:

- Search and filter orders
- Scroll through the orders page
- Press the "Track parcel" button to view parcel tracking details
- Visit the payment method page for each order

**Mobile-first:**
This prototype is focused on the mobile experience and is best viewed on a mobile phone. (Caveat: It has not been tested on many devices, only on a Samsung device and local simulator.)

## Getting Started

To check out and run the project locally:

1. Clone the repository:
   ```
   git clone https://github.com/petermarkellis/theverygroup-myordersprototype.git
   ```
2. Navigate to the project directory:
   ```
   cd theverygroup-myordersprototype
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Start the development server:
   ```
   npm run dev
   ```
5. Open the app in your browser (preferably on a mobile device or simulator):
   ```
   http://localhost:3000
   ```
